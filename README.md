# Hair Dryer Simulation

An interactive hair dryer built with HTML, CSS, and JavaScript.

## Run

Download the files together and open `index.html` in a browser. No installation or build step is required.

## Controls

- Starts Off. The first Power press starts at Low.
- Power turns the dryer off or restores the last speed used.
- Speed cycles Low → Medium → High → Low while powered on.
- Speed is disabled while Off.
- Low is green, Medium is orange, and High is red.
- Speed memory lasts until the page is refreshed.

## Files

- `index.html`: page structure and dryer illustration
- `styles.css`: layout, speed colors, and airflow animation
- `script.js`: power, speed cycling, and speed memory
